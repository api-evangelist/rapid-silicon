# Rapid Silicon

> Fabless semiconductor company (founded 2019, Los Gatos, California) building AI- and
> intelligent-edge-focused FPGAs and embedded FPGA (eFPGA) IP on an open-source technology base.
> Rapid Silicon sells silicon IP and locally installed EDA software. It does not operate a public
> web API, developer portal, or machine-readable API contract.

## Products

- Gemini FPGA family — AI and intelligent-edge focused FPGA devices.
- Vega eFPGA IP — embeddable standalone FPGA IP core with a customizable, scalable architecture
  spanning roughly 1.5K to 100K+ logic cells, with configurable BRAM and DSP MAC tiles, licensed for
  integration into a customer SoC.
- Rapid eFPGA Configurator — self-service tool for sizing Vega eFPGA resources (DSPs, BRAM, logic
  elements) ahead of an IP delivery engagement.
- Raptor Design Suite — RTL-to-bitstream FPGA compiler and GUI covering simulation, synthesis,
  placement, routing, bitstream generation and device configuration. Released by Rapid Silicon under
  GPL3 and described by the company as the first complete commercially available open-source FPGA
  tool-chain.

## Source code

- https://github.com/RapidSilicon — Rapid Silicon's own GitHub organization (12 public repositories,

- https://github.com/os-fpga/Raptor — the Raptor Design Suite compiler and GUI. This repository lives
  in the Open-Source FPGA Foundation organization, not in a Rapid Silicon organization; Rapid
  Silicon's own announcements identify Raptor as its tool-chain and this as where it is released.
